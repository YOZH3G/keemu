# ADR-0013: Opt-in synthetic event contracts (m1b-21)

Status: accepted for a host-local synthetic handler-contract slice only. A12 and MVP 1B remain BLOCKED.

`src/keemu/events.py` exposes `python -m keemu.events --contract FILE --root ABSOLUTE_PRIVATE_DIR --log ABSOLUTE_PRIVATE_DIR/events.jsonl --run-id ID --event boot|netfilter`. This is not `keemu event NAME EVENT`, a persistent environment operation, an Entware target hook, or a physical Keenetic observation. Contracts accept `source: synthetic:*` only; observed source, interface/USB/fd events and device-hook paths are unsupported. The test creates its own owner-only directories and scripts. No production scenario's netfilter event invocation or model/version has been observed, so generic profile YAML is not changed to assert a verified event mapping.

Schema version 1 fixes selection to all manifest-listed `NN-name` files in an owner-only `handlers` directory, ordered by filename, with SHA-256 per file and an executable-mode expectation. Unlisted files, symlinks, hash or mode changes fail before execution. The working directory is the private `work` directory, `PATH` is `/usr/bin:/bin`, and the process inherits no caller environment. Boot supplies only `KEEMU_EVENT` and the private state path; synthetic netfilter additionally supplies explicitly declared `KEEMU_TYPE` and `KEEMU_TABLE` (test fixture values `filter` and `ipv4`, not observed device values). Shell interpretation is not performed by the dispatcher: each checked executable script is invoked by path with no extra arguments. Nonexecutables follow explicit skip/fail policy; failures follow stop/continue policy. Per-handler timeout kills the launched process group. The private JSONL includes timestamp, run ID, synthetic source, selected handler, bounded allowlisted event environment, exit code, duration, timeout and status. It omits arbitrary caller environment and script output. Unknown event returns BLOCKED/exit 4, logs `unsupported-event` with redacted name, and does not execute a handler. Malformed/unsafe fixture exits 3; a failed handler or unmatched state exits 1. Successful synthetic dispatch exits 0.

Each contract lists exact allowed pre-event rule identifiers and a unique ordered post-event list, including the already-restored state as a valid repeat input. The test starts with a chain marker, changes only a test-owned JSON rule list, dispatches twice more, and checks exact restoration with no duplicated rule identifiers. This is an S0 rules-mock: no iptables/nftables operation, actual kernel rule, packet path, target executable, Docker container, host firewall mutation, or real rule restoration was tested. The scripts are explicitly trusted, hash-pinned local test fixtures rather than a sandbox for untrusted same-UID scripts; a concurrent same-UID file swap after verification is outside this boundary. Generic `keemu test`/`up` does not invoke this harness and JSONL is not an A21 report bundle. A12 requires a real scenario-specific event and firewall restoration proof, so it remains BLOCKED.
